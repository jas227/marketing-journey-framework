# Marketing Journey Framework

This repository installs the Marketing Journey Framework in Codex. It helps someone research a business, explore strategy across the 18 Atomic Units of Marketing, and create three coherent Customer Marketing Journeys through an interactive map.

## Install with Codex

Run these two commands:

```sh
codex plugin marketplace add jas227/marketing-journey-framework
codex plugin add marketing-journey-framework@marketing-journey-framework
```

Then start a new Codex task so the skill is loaded.

You can also give Codex this request:

> Install the Marketing Journey Framework plugin from https://github.com/jas227/marketing-journey-framework, verify that it is available, and tell me when to start a new task.

## Update to a later version

```sh
codex plugin marketplace upgrade marketing-journey-framework
codex plugin add marketing-journey-framework@marketing-journey-framework
```

## Try it

- Create a Marketing Journey Map for Stumptown Coffee Roasters.
- Map my business idea across the 18 Atomic Units of Marketing.
- Audit this marketing strategy and identify its weakest hypotheses.
- Compare two coherent marketing configurations for this company.

## What is included

- The current 18-unit framework and its six-stage structure
- Research and evidence standards
- Explore, Configure, Audit, Validate, and Compare modes
- Three Customer Marketing Journeys for company applications
- A canonical interactive left-to-right journey-map visual system, used consistently across companies
- A copy-and-paste prompt in `COPY-PASTE-PROMPT.md` for use when plugin installation is unavailable

The plugin contains instructions and templates only. It does not include a backend, external account access, saved boards, or previously generated company maps.
